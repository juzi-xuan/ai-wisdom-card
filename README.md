# AI 智慧卡片 · Wisdom Card

> 输入一句话，收获一张知识卡片 + 一份思想地图

AI 驱动的知识卡片生成工具，将碎片化的金句、感悟、摘抄，转化为结构化的个人思想资产。

---

## ✨ 项目愿景

现代人的困境：

- **信息很多，无法沉淀** — 收藏了 1000 篇文章，一个月后找不到在哪
- **只收藏，不理解** — 存了一堆金句，却没总结、没思考、没形成自己的知识体系
- **内容之间没有连接** — 稻盛和夫的话和《当下的力量》其实说的是同一件事，但你不知道

我们要做的是：

```
碎片化输入 → AI 理解 · 提炼 · 分类 · 关联 → 个人知识卡片 + 思想网络
```

不只是「生成一张漂亮卡片」，而是帮你构建属于自己的精神知识库。

---

## 🎯 核心功能

### 模块 1：AI 智能卡片生成（核心 MVP）

输入一段文字，AI 自动输出一张完整的知识卡片：

- **卡片标题** — 提炼核心主题，如《关于选择与遗憾》
- **原文展示** — 你摘抄的那句话
- **深度解读** — 这句话真正在说什么，为什么有力量
- **核心关键词** — #成长 #勇气 #行动力
- **多套视觉风格** — 极简风 / 治愈风 / 东方风 / 黑金高级风

### 模块 2：AI 思想解析（差异化价值）

不只是总结，更要回答「为什么这句话有力量？」

- **哲学来源** — 这句话源自哪种思想脉络（苏格拉底？斯多葛？东方哲学？）
- **核心思想** — 底层逻辑是什么
- **现实意义** — 适用于职业选择 / 人际关系 / 自我成长等哪些场景

### 模块 3：相似思想推荐（RAG 知识库）

从一句话延伸，打开更广阔的思想世界：

- **书籍推荐** — 精神内核相似的经典书籍 + 核心观点
- **电影推荐** — 主题契合的影片 + 推荐理由
- **人物语录** — 有类似思想的名人名言

知识库覆盖：
- 📚 100+ 经典书籍（《纳瓦尔宝典》《活着》《少有人走的路》...）
- 🎬 经典电影台词库（《肖申克的救赎》《阿甘正传》《星际穿越》...）
- 💭 名人语录库

### 模块 4：个人思想档案（高级功能）

当你收藏了 100 张卡片，AI 为你生成：

- **思想倾向分析** — 70% 成长类 / 20% 哲学类 / 10% 情感类
- **精神画像** — 「你关注长期成长、自我突破和人生意义」
- **AI 版个人年度总结** — 你的精神成长轨迹

### 模块 5：AI 每日灵感推送

每天随机推送一张卡片，配上：

- **今日金句** — 随机从你的收藏中挑选
- **深度解读** — 重温这句话的力量
- **行动建议** — 「今天完成一个拖延已久的小任务」

## 💡 创新功能（后续迭代）

### 创新 1：知识关系图谱

AI 自动在你的卡片之间建立关联，形成个人思想地图：

```
        成长
       /  |  \
     坚持 自律 长期主义
```

### 创新 2：AI 与你对话

基于你的收藏库，提供个性化建议：

> 你：「为什么我最近总感觉迷茫？」
>
> AI：「根据你的收藏，发现你最近关注成长、职业、自律，建议你……」

### 创新 3：一句话改写

同一句话，多种表达：

- **文学版** — [所有看似偶然的抵达，都源于漫长岁月里的不曾放弃。]
- **朋友圈版** —  [哪有什么突如其来的惊喜，不过是日复一日的坚持，终于在某天开出了花。]
- **演讲版** —  [各位，我想告诉大家 —— 这个世界上，从来没有真正的 "偶然成功"。
每一次看似幸运的降临，每一个水到渠成的时刻，背后都是无数个日夜的咬牙坚持。当你在黑暗中踽踽独行，当你想放弃又咬牙撑住的时候，你正在为未来的某一天，积蓄破土而出的力量。
所以，请相信：你今天所有的不放弃，都是明天惊喜的铺垫！]
- **哲学版** — [偶然，是时间对因果的温柔伪装。
我们称之为 "抵达" 的那个瞬间，不过是漫长量变终于突破了质变的阈值。放弃与不放弃，并非两个对等的选项 —— 前者是熵增的自然趋向，后者是对生命意志的逆向做功。
因而，所谓 "偶然的抵达"，本质上是一个人用持续的主体性，在混沌中凿出的确定性。]

### 创新 4：AI 卡片评分

自动为每句话打分：

- **深度指数** — ★★★★★
- **启发指数** — ★★★★☆
- **适用场景** — 人生选择 / 职场激励 / 情感治愈

## 🚀 实现路线图

### 第 1 阶段：MVP 跑通（3-5 天）

目标：先把核心流程跑通

- [ ] **Step 1**：注册 Dify 云端，创建 Chatflow
- [ ] **Step 2**：设计核心 Prompt
  - 你是一名知识卡片设计专家
  - 用户输入一段文字，完成：提炼主题 → 生成标题 → 深度解释 → 提取关键词 → 推荐书籍电影
  - 输出 JSON 格式
- [ ] **Step 3**：接入大模型（GPT / Claude / DeepSeek）
- [ ] **Step 4**：输出 Markdown 格式卡片，验证内容质量

### 第 2 阶段：视觉卡片生成

目标：从文字卡片升级为图片卡片

- [ ] AI 生成设计描述（主题、风格、比例）
- [ ] 调用图片生成 API
- [ ] 生成 3:4 比例精美卡片图片
- [ ] 多套模板切换（极简 / 治愈 / 东方 / 黑金）

### 第 3 阶段：RAG 知识库

目标：让推荐更精准、更有料

- [ ] 建立知识库目录结构

## 🎨 卡片模板

| 模板名称 | 风格描述 | 适用场景 |
|----------|----------|----------|
| **极简白** | 白色背景 + 黑色衬线字体 + 细边框 | 哲理、商务类内容 |
| **治愈风** | 马卡龙渐变 + 手写字体 | 情感、治愈类内容 |
| **东方韵** | 水墨质感 + 书法字体 + 印章 | 东方哲学、古诗词 |
| **黑金色** | 深色背景 + 金色点缀 + 高级排版 | 力量、励志类内容 |

卡片尺寸：**1080 × 1440 px**（3:4，适配小红书 / 朋友圈）
